# Changelog · flarum-poster

## 2026-10-28

### 新增：对外稿件纯净度硬约束
- SKILL.md 新增「对外稿件纯净度：只发成稿」一节。
- 禁止六类内容进入正文：内部对话原文、内部讨论过程、话题来源指认、他人经历冒用、内部规划草稿、可识别信息。
- 附发布前 grep 自查命令与「自检三问」。

### 新增：群聊素材预处理流程
- 四步：①抽出一句话的「问题」②拆「观点」（代号／核心主张／依据类型／可采信度）③给代号（A/B/C 或中性卡通昵称）④只写成稿。
- 明确禁止：真实姓名、微信昵称、「职业+姓氏」、「地名+身份」。
- 附检验法：删掉全部代号后文章仍成立 = 写了结论；不成立 = 写了过程。

### 新增：验证记录
- 记录两起违规案例与改法（249 冒用他人亲历、247 内部口径外泄），供后续复现。

### 变更：公众号抓取路径修正（markdown-proxy 相关）
- 见 markdown-proxy 技能 changelog；flarum-poster 侧同步了「先查原始来源」的引用规范。

## 2026-10-23

### 新增：发帖前自检清单
- 事实密度高的帖子先查原始来源（ClinicalTrials.gov / 指南原文），区分「登记口径／公司公告／作者预测」。
- 入组条件必须写死（如「只招 KRAS G12D、野生型不符合」）。
- 重要内容过 codex 复核，且必须逐条回原始登记库核验。

### 新增：原地 PATCH 纠错流程
- 改正文 `/api/posts/<id>`、改标题 `/api/discussions/<id>`、补回复 `POST /api/posts`。
- 改完必须重新 GET 回来抽查关键词。
